# いさむボーイ公式サイト

大道芸人「いさむボーイ」の公式サイトです。文章・出演予定・写真は JSON にあり、ページはそれを読み込んで表示します。更新は [Pages CMS](https://pagescms.org/) から行い、HTML は編集しません。

このリポジトリの内容は動作確認用です。芸名・予定・連絡先・画像はサンプルなので、本番公開の前に本人確認のうえ差し替えてください。

## ローカルで見る

リポジトリのルートで次を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。`index.html` を `file://` で直接開かないでください。JSON の読み込みに失敗します。

JSON を保存してページを再読み込みすると、表示が変わります。

## ファイルの役割

| パス | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み。見出しと並びだけを持つ |
| `css/style.css` | 見た目 |
| `js/site.js` | JSON の読み込み |
| `js/render.js` | 画面への描画 |
| `js/schedule.js` | 日付の判定と URL の確認 |
| `data/site.json` | 芸名・紹介・プロフィール・連絡先 |
| `data/events.json` | 出演予定（1ファイルの配列） |
| `data/performances.json` | パフォーマンス内容 |
| `data/history.json` | 経歴 |
| `data/achievements.json` | 出演実績 |
| `data/gallery.json` | 写真 |
| `images/` | アップロードした画像 |
| `.pages.yml` | Pages CMS の編集画面 |

画像の公開パスは `/images/...` です。サイトはドメインの直下（`/`）で公開する前提です。

## CMS で編集するもの

Pages CMS のメニューは次の6つです。

1. **出演スケジュール** … 日付、時間、場所、イベント名、備考、イベントページ、開催状況、公開スイッチ
2. **基本情報** … 芸名、肩書き、キャッチコピー、紹介文、ジャンル、活動エリア、出演時間、プロフィール文、画像、問い合わせ先
3. **パフォーマンス内容**
4. **経歴**
5. **出演実績**
6. **写真ギャラリー**

出演予定は1回保存すれば、「次の出演」と「出演スケジュール」の両方に反映されます。

表示ルール:

- `サイトに公開する` がオフの予定は出ません。
- 日本時間の今日より前の予定は出ません。当日の予定は、その日のうちは残ります。
- 日付の早い順に並びます。同じ日が複数あるときは、入力した順です。
- 開催状況が「中止」の予定は一覧に「中止」と出ます。「次の出演」には選ばれません。
- 今日以降の公開予定が無いときは「現在、公開中の出演予定はありません」と出ます。

## うまく表示されないとき

- ページに「情報を読み込めませんでした」と出る: ローカルサーバのルートがリポジトリ直下か、JSON のカンマや括弧が壊れていないかを確認します。ブラウザのコンソールにも失敗理由が出ます。
- 入れた予定が出ない: 公開スイッチ、日付が今日以降か、開催状況を確認します。中止の予定は「次の出演」には出ません。
- 画像が壊れて見える: 空欄の画像は表示しません。パスは `/images/` から始まるものを使います。
- CMS で保存したあと項目が消える: `.pages.yml` に無いキーは保存時に削除されることがあります。JSON のキー名と設定の `name` を同じにしてください。
- CMS の接続先: 開発用リポジトリと作業ブランチだけを選んでください。本番サイトへ自動では反映しません。
